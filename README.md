
# Cybersecurity Toolkit 🛡️

A beginner-friendly collection of Python tools developed
to explore cybersecurity, networking and security automation.

## About the Project

This project contains simple Python utilities that demonstrate
fundamental cybersecurity concepts through practical coding.

## Features

### 1. Password Strength Checker
Evaluates password strength based on length, uppercase,
lowercase, numbers and special characters.

### 2. Secure Password Generator
Generates random passwords using Python's secrets module.

### 3. File Integrity Checker
Calculates SHA-256 hashes to help identify file modifications.

### 4. IP Information Lookup
Resolves a domain name into its corresponding IP address.

### 5. TCP Port Scanner
Checks selected TCP ports on the local computer.

## Technologies Used

- Python 3
- Socket
- Hashlib
- Regular Expressions
- Secrets
- IP Address

## Installation

1. Install Python 3.
2. Clone this repository:

git clone https://github.com/rohancode77/Cybersecurity-Toolkit.git

3. Open the project directory:

cd Cybersecurity-Toolkit

## Usage

Run any program using:

python password_strength.py

python password_generator.py

python file_hash_checker.py

python ip_info.py

python port_scanner.py
